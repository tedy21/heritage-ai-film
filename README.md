# Heritage AI Film

An AI-powered storytelling project exploring Ethiopian heritage through cinematic short films generated with artificial intelligence.

## Project Overview

Heritage AI Film is a reproducible AI content-generation pipeline designed to transform structured storyboards into complete short films. It integrates generative AI models and automated media-processing tools to create visual scenes, animated video clips, narration, background music, and synchronized subtitles.

The project emphasizes modular architecture, reproducibility, efficient asset caching, transparent model usage, and responsible AI-generated content.

## Key Features

- Structured, schema-validated storyboards
- AI-powered image and video generation
- AI-generated narration and original background music
- Automated video assembly using FFmpeg
- Vertical (9:16) and horizontal (16:9) video outputs
- Dependency-aware caching to avoid unnecessary regeneration
- Execution logging and generation-cost tracking
- Documented experiments, failures, and ethical considerations

## Technology Stack

- Python
- Google Gemini API
- Cloudflare Workers AI / FLUX
- Wan 2.2
- ACE-Step
- FFmpeg
- JSON Schema
- Git and GitHub

## Project Goal

To demonstrate how generative AI models can be integrated into a modular, reproducible software pipeline for culturally meaningful digital storytelling.

**Note:** This project is an AI-assisted creative and engineering experiment. Generated media should be reviewed for cultural accuracy, consent, licensing, and responsible AI disclosure.
